# Project illustrations

`guard-cover.svg` is original editable vector artwork showing a shield at a
public gateway. It is conceptual, not an actual deployment or a guarantee that
every malicious connection will be identified.

`guard-paths.svg` and `guard-paths.zh-CN.svg` are equivalent architecture diagrams.
Their labels describe forwarded connection metadata and optional local SSH
authentication events. All labels and shapes are directly reviewable as source;
there are no embedded raster images, remote resources, scripts, logs, addresses,
account names or deployment mappings.

All three assets are provided under the repository's MIT license.
